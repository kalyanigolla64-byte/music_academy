SWARA SANGAMAM - INDIAN TRADITIONAL MUSIC ACADEMY

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

FILES
- index.html   Home page
- courses.html Courses page
- about.html   About page
- gallery.html Gallery page
- contact.html Contact/enquiry page
- style.css    Complete responsive design
- script.js    Mobile menu and enquiry form interaction

NOTE
The project uses remote image URLs from Unsplash, so an internet connection is needed for the photographs to display.
You can replace the academy name, phone number, email, and images with your own details.
